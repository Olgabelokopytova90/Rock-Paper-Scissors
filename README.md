

# ✊ Rock-Paper-Scissors (Console Version)

This is a simple first project text-based Rock-Paper-Scissors game built with JavaScript.  
The player plays against the computer — the first to reach 5 points wins!

## 🎮 How It Works

- The computer randomly picks Rock, Paper, or Scissors.
- The player is prompted to enter their choice via a pop-up prompt.
- The game compares both choices and updates the score.
- The game runs inside the browser's console.
- The first to score 5 points is declared the winner.

## 🧠 Logic Highlights

- Case-insensitive input handling (e.g., "rock", "Rock", "ROCK" all work)
- Random computer choice using `Math.random()`
- Clear structure: separate functions for getting choices and comparing them
- Basic score tracking using `let humanScore = 0` and `let computerScore = 0`

## 🛠️ Built With

- JavaScript (ES6)
- No external libraries — 100% vanilla JS

## 📌 Note

To play this game:
1. Open `index.html` in your browser
2. Open the browser **console**
3. Call the `playGame()` function
4. Enter your choices in the prompt
